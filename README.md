# 🔮 神秘命运占卜

一个移动端优先的神秘学主题 H5 互动占卜应用。用户通过输入姓名、选择星座、完成性格测试、抽取塔罗牌和符文，获得个性化的命运解读。

## 快速开始

直接用浏览器打开 `index.html` 即可运行，无需安装任何依赖。

```bash
# 克隆项目
git clone <repo-url> qiezi
cd qiezi

# 直接用浏览器打开
open index.html   # macOS
# 或双击 index.html（Windows）
```

- 纯 HTML + CSS + JavaScript（无框架、无构建工具）
